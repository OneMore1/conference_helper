# Maintaining this repository

This repository distributes one research workflow skill. It is not a research dataset.
The canonical skill lives at skills/conference-helper/; do not duplicate it under .agents/skills.
For code changes run `python tools/run_checks.py` and `python tools/demo.py`.
Keep runtime helpers Python 3.10+ standard-library only, offline, and safe against overwrites.
Keep examples synthetic. Never add private drafts, subject identifiers, API keys, experiment data or host-specific paths.
New original code, rules, templates and documentation are MIT-licensed. Preserve upstream attribution and the distinct MIT/CC BY license scopes; do not relicense third-party material.
Routing must distinguish observed progress, recommended next step, and the user's requested task.
A section is not a completed manuscript. A prepared submission package is not a submitted paper.
Do not change remote settings, publish a release, run research jobs, or submit a paper without explicit authorization.
