# 07 Rebuttal 与最终修改

读取实际 reviews、当前稿件、已有回复和当年讨论期规则。
建立 reviewer → concern → evidence → response → manuscript change 的对应表。
同一科学问题被多名审稿人提出时可以共用证据，但保持各自回复位置清楚。

先回答直接问题，再提供最相关证据与修改定位。区分澄清、补分析、实际修改和明确不同意。
不虚构已经完成的实验、修改位置、审稿人认同、评分变化或录用信号。
回应误解时解释原设定与已修改表达，不猜测审稿人动机或能力。
用户认为某条不是问题时，重新读证据与论断，不能反复输出同一未经支持的批评。
不要把 rebuttal 式防御口径机械迁移到摘要、引言与结论。
先遵守响应长度、允许上传内容和匿名性限制，再准备最终文本。
