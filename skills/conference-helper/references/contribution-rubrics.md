# 贡献分型：不要用同一把尺子评价所有论文

以下是本包的建议量表，不是对会议偏好的统计结论，也不是原论文评测指标的复现。
共同问题：重要吗；相对最近邻增加什么；证据能排除什么替代解释；适用范围是什么。

| 类型 | 核心证据 | 应避免的错误要求 |
|---|---|---|
| method | 设计为何解决瓶颈、强基线、公平预算、可解释消融、泛化或效率 | 为了新颖而堆模块或强加无必要理论 |
| diagnostic | 测量能否分离解释、控制混杂、跨设定稳健、发现能否改变认识 | 强制附加新模型才算贡献 |
| empirical | 明确问题、有效比较、稳健估计、边界条件、可复现的新观察 | 把所有观察升级为机制或因果 |
| theory | 清晰命题、适用假设、证明、与已有结果的边界及含义 | 用实验替代应有证明，或要求纯理论稿必须大规模跑模型 |
| dataset | 数据独特性、质量、许可与隐私、覆盖、基准和复用价值 | 仅按算法机制深度打分 |
| systems | 真实约束、端到端收益、资源与硬件条件、可部署性和复现 | 只看 FLOPs/单模型精度而不看系统任务 |

混合贡献选一个主类型，辅类型服务主论断，不通过增加类型数量抬高评价。
文献模式是工具，不是必需标签。可测量的清楚问题比“模式命中数”重要。
