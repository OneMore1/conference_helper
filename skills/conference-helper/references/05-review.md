# 05 模拟审稿与修改优先级

先读当前版本和真实结果，不从历史评论直接复用批评。
选择 contribution-rubrics.md 中匹配的类型，再参考目标会议当年的 reviewer guidelines。
每条主要意见必须包括：被审查的具体论断/位置、可观察依据、为何影响核心结论、最小修复方式。
将“确认的事实/实现错误”“关键证据缺口”“有价值但非必需的增强”分开。
没有发现问题就不要为了数量捏造问题；不要要求所有论文都做所有可能实验。

重点检查：问题重要性、与最近邻差异、方法与问题匹配、结果能否支持论断、评估公平性与泄漏、可复现描述。
计分仅用于内部相对比较，不是会议真实录用分数，更不能直接映射为概率。
分清提案审查与完整论文审查：没有跑实验的提案不能因尚无结果被当作论文失败，完整稿却必须有结果依据。

采用独立上下文复查时，不向审查者提供生成者的自我评分。
只有同一会话顺序复查时，称为第二遍检查，不称盲评或独立评审。
审稿意见用于任务改进，不将每一条变成正文的提前防御。

用 [研究 Tips](review-tips.md) 识别材料中实际触发的风险。把原文经验转为具体意见与最小修复，不以模式标签或历史比例代替当前稿件的证据评价。

## 路由
分析错误 → analysis；缺必要证据 → supplement；表达/结构问题 → writing；规则/匿名问题 → submission。
不因发现局部问题就重做全部选题。用户只要求审阅时交付审阅，不擅自改稿或启动实验。
