# 补充：最小必要的证据修复（本包扩展）
补充模块首先审计缺口，不默认追加实验，也不追求把每个结果都变成显著。
每个缺口记录：gap_id、对应 claim_id、缺口证据、影响范围、优先级、最小动作、成本、停止条件。
优先级：blocking=当前核心论断缺少必要依据；supportive=提升可信度；optional=扩展范围。
可选动作：核对已有文件、重分析、补统计/对照/消融、外部验证、澄清方法、减少论断、保留负结果、移至后续研究。
先判断能否通过已有数据和合理限制论断解决，再考虑新采集或大规模训练。
预先记录新实验将区分的解释和决策规则；执行结果不好时不悄悄换规则。
已看过结果后形成的新假设标记探索性，必要时另设验证数据，而非重复使用测试集确认。
用户只请求写作时，可以将关键缺口列入独立 memo，同时继续处理有证据的部分。
需要消融时按 [消融计划](../assets/ablation-plan.md) 连接论断、对照和判定，优先解释最值得先补的一项；材料未提供的部件、结果和成本保持未知。
按 [研究 Tips](review-tips.md) 优先选择能改变核心判断的最小动作，已有证据足够时不为完整清单追加实验。
交付缺口计划；有持久化工作区且允许写入时保存 artifacts/gap_plan.md。有新实验 → design/execution；只有新分析 → analysis；
仅修正范围/表达 → writing。缺口解决并不必然意味着新增实验。
