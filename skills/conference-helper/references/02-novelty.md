# 02 文献与创新重合核查

先将创新拆成四个比较维度：问题设定、核心机制、关键见解、适用范围（借鉴 S5）。
以机制及其同义表达检索，而不只搜模型名或当前领域术语。题目/摘要用于筛选，关键判断依赖相关正文。
记录检索日期、数据库、查询词、时间范围、失败连接和阅读覆盖。
每条文献有可核实的标识符/链接、版本、阅读位置与其实际支持的表述。
模型回忆只能作为待核查线索，不进入最终已验证引用表。

比较表采用：文献 → 相同部分 → 真实差异 → 定位证据 → 对核心论断的影响。
逐项标为 match / partial / different / unknown，避免将不确定信息强制二值化。
重点处理最接近的工作，不让大量不相关论文稀释一个决定性的重合。
零结果、检索故障或关键全文不可得时，结论为检索不足；持久化记录使用 novelty_assessment.status=insufficient_search，不宣称新颖性已确认。
“本轮未发现精确重合”不是“全球首次”的证明。

最后给出差异句：相对于工作 A 在条件 Y 下实现的 X，本研究改变 Z，并用实验 E 区分该变化是否带来能力 W。
还没有结果时使用假设/计划语气，不写已经获得收益。
论文重命名通常只需表示层复查；核心机制、目标或数据设定变化时重新核查相关近邻工作。

核查影响当前研究判断的相关方法、实验设定和代码版本；论文与实现不同之处分别定位。把可复用操作、适用条件和待验证差异接回本轮问题，不将文献阅读自动展开为单篇解读产物。

## 与原方案的区别
保留四轴比较，不将轴数自动换算为用户的创新总分或录用概率。
尤其不采用“没有检索到文献就给最高新颖性”的捷径。
允许保留不确定性，但把不确定项放在内部记录，不反复侵入论文叙事。
