# 宿主能力映射

Windows 上优先从短路径源码目录调用 CLI，将研究目录作为普通路径参数传入。只有独立安装的深路径技能时，可对脚本入口使用 Windows 扩展绝对路径（驱动器路径 `\\?\C:\...`；UNC 路径 `\\?\UNC\server\share\...`）；它属于工具调用细节，不要求用户改注册表。
如果 Python 报 `can't open file` 且代码尚未开始执行，先核对入口存在性与路径长度，使用上述入口方式后重试；不能据此判定工作区丢失。脚本启动后会自行处理研究目录和本地记录的路径。

Skill 是工作流，不包含 API 密钥，也不会自行获得服务器或文件权限。

| 当前任务 | 优先使用 | 降级方式 |
|---|---|---|
| 读取项目材料 | 用户附件、项目文件工具、已授权本地目录 | 只询问决定下一动作的缺失材料 |
| 文献及会议核查 | 公共检索、出版社原文、官方会议指南 | 使用现有来源并记录日期与范围，不宣称最新或排除重合 |
| 表格与统计分析 | 宿主的 Python / R / SQL 与数据分析工作流 | 交付方法、输入要求和代码，明确未执行 |
| 实验执行 | 已授权计算环境 | 生成脚本、资源估计和检查项，不虚报完成 |
| 科研图 | 对应的数据可视化或示意图工具 | 先给图的科学问题、数据映射和可编辑结构说明 |
| DOCX / PDF / LaTeX | 宿主的文档技能与编译工具 | 输出源文件并注明未渲染，不以文本检查代替视觉检查 |
| 状态与来源 | 本包的离线脚本 | 无文件环境时输出阶段卡与简短交接说明 |
| GitHub / 投稿系统 | 已连接且获授权的目标服务 | 不请求用户把令牌粘贴到聊天，不自动改变权限 |

不能把测试夹具、示意数据或初步假设登记为真实实验结果。
