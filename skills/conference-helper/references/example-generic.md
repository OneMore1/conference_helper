# 通用教学例子：有初步结果，也已经有初稿

本例完全虚构，不对应用户研究或原论文实验。

用户：已经完成部分模型评测，也有初稿。先看看结果能支持什么，不要重新选题。

材料：研究问题说明、实验计划、带版本的结果表、一个方法章节。

阶段卡应区分：已经进入写作、建议优先分析、当前执行分析。不能因方法章节存在就认定整篇可投。
分析应输出观察、支持的论断、替代解释和适用范围。未完成验证记入内部缺口表。

随后用户只要求修改 Methods：本轮切换 writing；保留未解决的分析缺口，不强制追加实验。
章节完成记录 scope=section；不把内部审阅提升为整篇定稿或投稿回执。

自动路由演示见仓库 tools/demo.py；它只运行合成状态，不生成或分析研究结果。
