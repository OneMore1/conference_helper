# 执行准备和实际执行核查（本包扩展）
读取冻结的实验计划、代码入口、环境说明、资源权限和用户授权。
先检查数据版本、split、seed、输出目录和小规模 smoke test；禁止覆盖原始结果。
命令/Slurm 脚本是准备产物；只有真实日志、退出状态和结果文件才说明执行过。
将 script_written / launched / running / failed / completed 分开记录。
没有服务器连接时交付命令与需要用户返回的日志，不能声称“已经在跑”。
实际启动需要明确范围与预算授权；已有授权覆盖时直接执行，不重复确认。不从“准备脚本”推断下载、联网传输或高成本作业的授权。
有初步结果的部分可以先进入 analysis，不要求全部任务结束。
执行记录至少说明代码版本、参数、输入版本、运行环境、输出定位和实际执行状态；有工作区且允许写入时保存 run_manifest，临时或只读核查在交付中保留这些信息。
